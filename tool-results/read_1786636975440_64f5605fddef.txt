    82→## Project Overview
    83→
    84→HIREMIND AI is an AI-powered recruitment assistant (Smart Resume Parser & Mock Interviewer). Core intelligence loop:
    85→
    86→```
    87→RESUME + TARGET JOB
    88→   -> CANDIDATE INTELLIGENCE
    89→   -> SEMANTIC JOB MATCH (Prototype Job Match Index)
    90→   -> SKILL GAP INTELLIGENCE
    91→   -> GAP-DRIVEN ADAPTIVE INTERVIEW  (THE WOW FEATURE)
    92→   -> ANSWER EVALUATION
    93→   -> COMPETENCY STATE UPDATE
    94→   -> JOB READINESS (Prototype Job Readiness Index)
    95→   -> PERSONALIZED IMPROVEMENT ROADMAP
    96→```
    97→
    98→Design philosophy: Apple-inspired premium UX (clean / sleek / minimal / premium / human). Light-first, warm-neutral background, charcoal text, restrained accent.
    99→
   100→Tech stack: Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + shadcn/ui + Prisma (SQLite) + z-ai-web-dev-sdk (LLM) + Zustand + Framer Motion.
   101→
   102→Critical principles:
   103→- AI understands. Application logic decides. Deterministic scoring.
   104→- Distinguish KNOWN / WEAK / UNKNOWN evidence. Never treat absence as proof of missing skill.
   105→- Adaptive interview: next question MUST depend on previous answer (the demo's WOW moment).
   106→- Demo mode must work reliably end-to-end (10+ consecutive runs).
   107→- Prototype-labeled indices (never "hiring probability").

   324→### Known Issues
   325→1. **AI Timeout**: z-ai-web-dev-sdk occasionally times out on the first call (25s timeout). The deterministic fallback handles this gracefully, but it means the demo sometimes starts with "fallback" quality parsing. **Mitigation**: Already handled with fallback; could increase timeout or add retry logic.
   326→2. **Zustand store is client-side only**: Page reload resets all state. The session data persists in SQLite via the API, but the client-side view state is lost. **Recommendation**: Add URL hash-based view state persistence (e.g., `#view=match&session=xxx`) so refreshing preserves the current view.
   327→3. **Match index for demo candidate is 53 (fair)**: This is correct but some gaps (Databases, Microservices) are flagged as critical even though the candidate has SQL/PostgreSQL/REST APIs evidence. This is because the AI didn't always extract strong-enough evidence sentences for these. **Recommendation**: Improve the resume parser prompt to always extract evidence for well-known skills mentioned in the skills section.
